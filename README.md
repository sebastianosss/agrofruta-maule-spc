# AgroFruta Maule · Panel SPC

Aplicación Streamlit para presentar el taller IES-325. Lee el libro Excel incluido en esta carpeta y muestra cartas de control interactivas con Plotly.

## Ejecutar localmente

```bash
python -m pip install -r requirements.txt
python -m streamlit run app.py
```

## Publicar en Streamlit Community Cloud

1. Crea un repositorio en GitHub con los archivos de esta carpeta.
2. En [Streamlit Community Cloud](https://share.streamlit.io/), inicia sesión con GitHub y elige **Create app**.
3. Selecciona el repositorio y la rama, e indica `app.py` como archivo principal.
4. Despliega la aplicación y comparte la URL que genere.

La app y el Excel se publicarán junto con el repositorio. Usa un repositorio público solo si estás de acuerdo con que el código y los datos del libro sean accesibles públicamente.
